## 🔁 Discovery Approach
The cell followed a 7-step sequence:

1. AS-IS Discovery — understand how things currently work
2. Evidence Collection — gather raw signals from real sources
3. Pain Point Identification — convert evidence into defined pain points
4. Categorization & Stakeholder Analysis — group pain points, map affected users
5. Prioritization — score and rank using objective criteria
6. Root Cause Analysis — validate underlying causes (5 Whys / Fishbone)
7. Validated Problem Statements → Business Needs — finalize inputs for the next cells

## ⚖️ Prioritization Matrix
Weighted scoring was used instead of subjective ranking:

| Criterion | Weight | Question |
|---|---|---|
| Frequency | 30% | How often does the problem occur? |
| User Impact | 30% | How strongly does it affect the trainee/user? |
| Business Impact | 25% | How strongly does it affect bootcamp operations? |
| Urgency | 15% | How quickly does it require attention? |

Formula: Weighted Score = (Frequency × 30%) + (User Impact × 30%) + (Business Impact × 25%) + (Urgency × 15%)
