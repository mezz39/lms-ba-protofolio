# Business Analysis Bootcamp LMS — Portfolio

## 📌 Project Overview
A specialized Learning Management System (LMS) designed for a Business Analysis Bootcamp, built to manage the complete learner journey — connecting learning, practice, assessment, mentor feedback, and skill development in one centralized platform.

Currently, trainees rely on multiple disconnected tools (WhatsApp, Drive, Zoom, Email) with no unified way to track progress, receive feedback, or demonstrate skill growth. This project addresses that gap.

Vision: A centralized learning platform that manages the complete BA bootcamp journey and enables real skill development.

## 🧩 Project Structure
The project was executed across 8 specialized cells, each responsible for a distinct phase of the Business Analysis lifecycle:

| # | Cell | Focus |
|---|------|-------|
| 1 | [Discovery & Framing](./01-discovery-framing) | Problem definition, stakeholders, root causes, pain point prioritization |
| 2 | [BRD](./02-brd) | Business Requirements Document |
| 3 | [Process Analysis](./03-process-analysis) | AS-IS / TO-BE process mapping, pain points |
| 4 | [Requirements Specification](./04-requirements-spec) | Functional & non-functional requirements, business rules |
| 5 | [User Stories](./05-user-stories) | Backlog, acceptance criteria, prioritization |
| 6 | [Data Analysis](./06-data-analysis) | Data flows, dictionaries, source mapping |
| 7 | [UI / Wireframing](./07-ui-wireframing) | User flows, information architecture, wireframes |
| 8 | [Documentation & Presentation](./08-documentation) | Final consolidation, demo day deliverable |
